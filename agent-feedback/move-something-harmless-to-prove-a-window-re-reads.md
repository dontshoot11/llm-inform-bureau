# To prove an open window re-reads the machine, move the one fact you can move from outside

When: a criterion says the open window notices a change — a permission given, a source that has
appeared — and the change itself is somebody's permission, which cannot be handed back and
forth to test with.
Do: move a harmless fact in the same list instead. `touch` the executable of the running bundle
and the checkup's "the copy that is running" row must show the new build time after the window
comes back to the front; the process keeps running, nobody's permissions are touched, and the
answer separates "the window is not re-reading" from "the machine really still says no".
Why: without a fact that can be moved on demand, a row that fails to change is two different
bugs wearing the same face, and the user ends up toggling permissions to tell them apart.
